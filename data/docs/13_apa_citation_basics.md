# APA Citation Basics
This course uses APA 7th edition. An in-text citation has the author's last name and the year, for example (Smith, 2024). For two authors use both names. For three or more authors use the first author followed by "et al."
The reference list goes on a new page titled References, in alphabetical order, with a hanging indent. A web page reference lists the author, the date, the title, the site name, and the link.
Use quotation marks and a page number for direct quotes, and keep quotes short. In most cases, paraphrasing with a citation is better than quoting.
